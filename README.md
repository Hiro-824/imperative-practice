# 王冠と、ことばの騎士 — The Missing Crown

英語の命令文と依頼文を使い分けながら、消えた王冠を取り戻すブラウザRPGです。
`docs/reference/prompt.txt` のシナリオ1を、全5幕・18回の依頼として実装しています。

## 起動

Node.js 20.9以上を使用してください。

```sh
npm ci
npm run dev
```

http://localhost:3000 を開きます。本番用は `npm run build` → `npm start` です。
Turbopackがローカルポートの制限に阻まれる環境では、`npm run build -- --webpack`、`npm run dev -- --webpack` を使えます。
外部フォントや外部APIキーを用意する必要はありません。背景・人物はローカルのWebP画像です。

## 遊び方

1. プレイヤーの名前と性別を決め、必要なら3回のチュートリアルを行います。名前を空欄にすると性別に応じた名前が自動で入ります。
2. マイクボタンを押し、英語の空欄部分を話します。目的語を含む文全体でも回答できます。
3. 声が出せない場合は「語句を選ぶ」に切り替えます。タップで選択・取り消し、ドラッグで並べ替え、「次へ」で送信できます。
4. 各場面は「プレイヤーの心の声 → 依頼操作 → 相手の反応」の順に進みます。

この物語の身分設定では、従者には動詞の原形、同僚には `Can you + 原形`、伯爵には `Would you mind + ing形` を使います。それぞれ6回ずつ練習します。実際の英会話では、親しさや状況に合わせて丁寧さを選びます。

身分に合わないが文法的には正しい依頼は「敬意レベルの選択ミス」として、NPCが反応したあとに再試行します。`Would you + 原形` は文法ミスではなく、同僚には自然な依頼、従者と伯爵には敬意レベルの選択ミスです。`Would you mind open` は文法エラーです。大文字・小文字、句読点、アポストロフィ、余分な空白は吸収します。

## 音声と保存

- 入力は Web Speech Recognition API を使用し、音声入力を既定にしています。HTTPSまたはlocalhostとマイクの許可が必要です。認識エンジン・対応言語・ネットワーク接続はブラウザに依存します。Chrome等の対応ブラウザを推奨します。
- 未対応、マイク拒否、ネットワークエラー、無音時は再試行または語句モードへ移れます。無音・認識失敗は不正解として数えません。
- 読み上げにはブラウザの `speechSynthesis` を使用します。英語のセリフだけを、キャラクターの性別に合う英語音声で読み上げます。
- 名前、性別、音声設定、チュートリアル受講、進行、手がかり、回答記録を `localStorage` の `crown-quest-v1` に保存します。語句の組み立て途中は保存せず、再開時は現在の問題からです。最後まで到達すると進行記録を削除します。

## 構成

| 場所 | 内容 |
| --- | --- |
| `lib/story.ts` | 18場面、3回の練習、人物、幕、依頼、訳、結果、手がかり |
| `lib/answer.ts` | 入力の正規化、文法・丁寧度の判定、語句候補 |
| `lib/speech.ts` | 音声認識のブラウザ対応と読み上げ |
| `components/game.tsx` | 進行、日英会話、入力UI、設定、保存、完了メーター |
| `components/scene.tsx` | `art-new` の背景差分、立ち絵、吹き出し絵、ドラゴン演出 |
| `public/art-new/` | 背景、人物アトラス、吹き出し用アイテム素材 |

画面は背景・立ち絵・必要な吹き出し絵・日英セリフで統一しています。人物とアイテムは `art-new` のアトラスから描画時に切り出し、チュートリアル、地下倉庫、大広間では進行に応じて開閉差分の背景へ切り替えます。王冠を持ったドラゴンだけは大きく浮遊します。動きを減らすOS設定にも対応します。

## 検証

```sh
npm run lint
npm test
npm run test:e2e
npm run build
```

`npm test` は18場面すべての正解・丁寧度の不一致・原形とingの区別・表記揺れ・空入力を検証します。

PlaywrightのE2Eでは全18問の会話順、日英表示、誤答分類、チュートリアル、保存・再開・完了時の保存削除、音声認識を検証します。`/usr/bin/chromium` がなければ `npx playwright install chromium` でブラウザを用意してください。`CHROMIUM_PATH` でも指定できます。ポート3000の開発サーバーがあれば再利用します。

音声テストはWeb Speech APIのイベントを模擬しています。実際のマイク認識精度、端末固有の音声、iOS/Android実機での操作は実機確認が必要です。
